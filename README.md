# Site Web Nadia Accompagne 🎓

Site web professionnel pour les services de coaching scolaire et accompagnement éducatif.

## 🚀 Comment utiliser le site

### Option 1 : Serveur Local (Test)
```bash
# Dans le dossier du projet
python3 -m http.server 8000
```
Puis ouvrez votre navigateur sur `http://localhost:8000`

### Option 2 : Hébergement Web
Uploadez simplement le fichier `index.html` sur votre hébergeur web (OVH, 1&1, etc.)

## 🔧 Personnalisation

Pour modifier le site :

1. **Couleurs** : Modifiez les variables CSS dans la section `:root`
2. **Contenu** : Éditez directement le HTML
3. **Images** : Remplacez l'icône placeholder par de vraies photos
4. **Informations légales** : Complétez le footer avec vos vraies données
